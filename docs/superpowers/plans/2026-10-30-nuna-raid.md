# 누나 레이드 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** URL 하나로 최대 4명이 접속해 1인칭으로 거대 돼지괴물 "누나"를 잡는 협동 보스전 웹게임을 만든다. 호스트 PC의 Node 서버 + Cloudflare quick tunnel로 공개한다.

**Architecture:** 서버는 전송(ws)과 분리된 순수 게임 모듈(`server/game/*`)이 20Hz 틱으로 보스·투사체·무기 스폰·피격·넉백·승패를 권위적으로 계산하고 스냅샷을 뿌린다. 클라이언트(Three.js, 번들러 없음)는 자기 이동만 권위적으로 처리해 20Hz로 보고하고, 서버가 보낸 넉백 임펄스를 자기 물리에 더한다. 모든 모델은 BoxGeometry + CanvasTexture로 코드 생성한다.

**Tech Stack:** Node 22 (ESM), `ws`, `three`(node_modules에서 `/vendor/three.module.js`로 정적 서빙 + importmap), `cloudflared`(npm, quick tunnel), 테스트는 `node:test`, 클라이언트 스모크는 `~/.npm/_npx/e41f203b7505f1fb/node_modules/playwright-core`(이미 설치된 Chromium).

**Spec:** `docs/superpowers/specs/2026-10-30-nuna-raid-design.md`

## Global Constraints

- Node 22, `"type": "module"`, 의존성은 `three`, `ws`, (dev) `cloudflared`만.
- 번들러 없음. 클라이언트는 ESM + `<script type="importmap">{"imports":{"three":"/vendor/three.module.js"}}`.
- 서버 틱 20Hz(50ms), 클라이언트 입력 보고 20Hz. 메시지는 JSON `{type, ...}`.
- 서버 하나 = 방 하나, 최대 4명, 5번째는 `{type:"error", reason:"full"}` 후 종료.
- 맵 이름 "낙성대동굴". 보스 이름 "누나". 모든 UI 문구는 한국어.
- 맵 48×48(1블록=1m), 좌표 원점 = 섬 중앙, 섬 범위 x,z ∈ [−24, 24], 지면 y=1(블록 윗면), 낙사 y < −10.
- 수치는 모두 `server/game/constants.js`에서만 정의하고 다른 파일은 import해서 쓴다(튜닝 시 한 파일만 수정).
- 실행: `npm start`(PORT 기본 3000), `npm run tunnel`, `npm test`, `npm run sim`.
