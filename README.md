# 누나 레이드 — 낙성대동굴

거대 돼지괴물 **누나**를 최대 4명이 1인칭으로 협동해서 잡는 웹 게임입니다. 호스트가 자기 컴퓨터에서 서버를 켜고 공개 주소를 친구들에게 보내면, 어디서든 브라우저로 들어와 같이 플레이할 수 있습니다. 목숨은 각자 3개, 섬 가장자리는 낭떠러지라 누나에게 밀려 떨어질 수 있습니다.

## 실행 (호스트)

```bash
npm install
npm start          # http://localhost:3000
npm run tunnel     # 다른 터미널에서: 공개 주소(https://….trycloudflare.com) 발급
```

- `npm run tunnel` 을 실행하면 터미널에 공개 주소가 크게 출력되고, 로비 화면의 **초대** 칸에도 자동으로 나타납니다. "공개 주소 복사" 버튼으로 복사해 친구에게 보내세요.
- 첫 실행 때 `cloudflared` 바이너리를 내려받습니다(인터넷 필요). 계정이나 로그인은 필요 없습니다.
- 같은 와이파이 안에서만 할 거면 터널 없이 `http://<호스트 IP>:3000` 으로 들어와도 됩니다.

## 플레이

1. 주소로 들어가 닉네임(2~12자)을 적고 입장합니다. 첫 입장자가 호스트입니다.
2. 호스트가 난이도를 고르고 **시작**을 누릅니다. 1명이어도 시작할 수 있습니다.
3. 게임 중에 들어온 사람은 관전하다가 다음 판에 참여합니다. 5번째 접속은 거절됩니다.
4. 누나를 쓰러뜨리면 승리, 전원 목숨 0이면 패배. 결과 화면에서 호스트가 **다시 하기**를 누르면 로비로 돌아갑니다.

### 조작

| 키 | 동작 |
| --- | --- |
| 화면 클릭 | 마우스 잠금 (Esc 로 해제) |
| W A S D (또는 방향키) | 이동 — 한/영 상태와 상관없이 키 위치로 인식 |
| Space | 점프 (땅찍기는 공중에 있으면 피해 없음) |
| 좌클릭 | 공격 / 활 발사 / TNT 투척 |
| 1 / 2 / 휠 | 근접 무기 ↔ 활·TNT 전환 |
| Shift | 질주 (신발을 주운 뒤 25초 동안만, 1.7배) |

### 무기

기본은 나무 검(56). 섬 곳곳에 6초마다(최대 8개) 무기가 떠오르며 가까이 가면 자동으로 줍습니다. 근접 무기는 철(112)→다이아(160)로 더 좋은 것만 바뀌고, 활(90, 30발)·**기관총**(22×연사, 80발, 좌클릭을 누르고 있으면 자동 발사)·TNT(260, 3개)는 특수 칸 하나를 씁니다. **신발**을 주우면 25초 동안 Shift 로 질주(1.7배)할 수 있고, 또 주우면 시간이 새로 채워집니다. TNT 는 자기도 다칩니다(25). 때리면 피해 숫자가 뜨고 누나가 붉게 번쩍이며 움찔합니다.

### 누나의 공격 — 돌진만 옆으로, 나머지는 점프로 피합니다

- **물기** ("누나가 문다! 점프!"): 가까이 붙으면 머리를 치켜든 뒤 0.45초 만에 뭅니다. 그 순간 공중에 있으면 안 물립니다.
- **돌진** ("누나가 돌진 준비! 옆으로!"): 0.8초 뒤 18m/s 로 직선 10m 돌진. 맞으면 돌진 방향으로 **9m** 밀려납니다. 점프로는 못 피하고 옆으로 빠져야 합니다. 마지막 단계에선 연속 3회(어려움 4회).
- **땅 찍기** ("누나가 땅을 찍으려 한다! 점프!"): 0.7초 뒤 반경 7m 광역 + 바깥쪽으로 **7m** 넉백. 공중이면 무효.
- **포효** ("누나의 포효! 점프!", 체력 60% 이하부터): 0.5초 뒤 반경 10m 안의 땅에 있는 플레이어가 2.5초간 느려집니다. 공중이면 무효.
- 점프 판정은 터널 지연을 감안해 "직전 0.3초 안에 공중이었으면" 인정됩니다.
- 체력 60%·30% 에서 단계가 올라 더 빨라지고 공격이 잦아집니다.
- 누나는 나무·바위를 **통과하지 못합니다**. 뒤에 숨으면 쫓아오지 못하고, 돌진하다 장애물에 부딪히면 1.2초 비틀거립니다("누나가 비틀거린다! 때려!").
- 누나 몸은 단단해서 안으로 들어갈 수 없고, 누나가 밀고 오면 밀려납니다(가장자리에서는 떨어질 수 있음).

가장자리 9m 안쪽에서 맞으면 떨어질 수 있습니다. 중앙 12m 안에서는 한 번 맞아서는 떨어지지 않습니다.

### 난이도

| 난이도 | 누나 체력 | 누나 피해 | 공격 간격 | 마지막 단계 연속 돌진 |
| --- | --- | --- | --- | --- |
| 쉬움 | ×0.7 | ×0.7 | ×1.3 | 2회 |
| 보통 | ×1 | ×1 | ×1 | 2회 |
| 어려움 | ×1.4 | ×1.3 | ×0.8 | 3회 |

누나 체력은 인원수에 따라 ×0.75 / ×1.5 / ×2.2 / ×2.8 로 늘어납니다(시작 시 고정). 봇 시뮬레이션(예고를 70% 피하는 "보통 사람" 봇) 기준 4인 보통은 약 1분 10초, 실제 사람은 봇보다 덜 맞혀 2~4분쯤 걸립니다. 너무 쉬우면 `server/game/constants.js` 의 `BOSS.baseHp` 를 올리세요. 혼자 보통은 모든 공격이 한 명에게 몰려 어렵고(봇 승률 75%), 혼자면 쉬움을 추천합니다. 어려움은 손발이 맞는 팀용입니다. `npm run sim [인원] [난이도] [시드 수]` 로 직접 재볼 수 있습니다.

## 트러블슈팅

- **터널 주소가 바뀌었어요**: 임시 터널은 `npm run tunnel` 을 다시 켤 때마다 새 주소가 나옵니다. 서버(`npm start`)는 그대로 두고 터널만 다시 켜면 로비의 주소도 갱신됩니다.
- **게임 중에 연결이 끊겼어요**: 같은 브라우저로 60초 안에 다시 들어오면 목숨·무기·기여도를 그대로 이어서 합니다. 끊긴 동안은 누나가 공격하지 않습니다. 60초가 지나면 탈락 처리됩니다.
- **방이 가득 찼다고 나와요**: 최대 4명입니다. 한 판이 끝나고 누군가 나가면 들어올 수 있습니다.
- **화면이 안 움직여요**: 화면을 한 번 클릭해 마우스를 잠가야 움직입니다. Esc 나 탭 전환으로 잠금이 풀리면 캐릭터는 멈춥니다.
- **소리가 안 나요**: 브라우저 정책상 첫 클릭 뒤부터 효과음이 납니다.

## 개발

```bash
npm test                        # 서버 단위 테스트
PW_PATH=<playwright-core 경로> node tests/e2e/lobby.mjs   # 로비 e2e (헤드리스 크로미움, playwright-core 필요)
node tests/e2e/play.mjs         # 입장→시작→낙사→승리→다시 하기 e2e
node tests/e2e/controller.mjs   # 1인칭 물리·넉백·낙사
node tests/e2e/scene.mjs / world.mjs / hud.mjs   # 렌더 스모크 + 스크린샷
```

구조: `server/` (Node 22, `ws`) 가 누나·전투·픽업·승패를 모두 판정하고 20Hz 로 스냅샷을 보냅니다. 클라이언트(`client/`, Three.js)는 자기 이동만 직접 계산해 보고합니다. 설계 문서는 `docs/superpowers/specs/`, 구현 계획은 `docs/superpowers/plans/` 에 있습니다. 게임 수치는 전부 `server/game/constants.js` 에 있습니다.
